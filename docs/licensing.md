# Licensing

| Material | Licence | Why |
| --- | --- | --- |
| Website source code, scripts, tests | **Apache-2.0** (`LICENSE`) | Permissive, with an explicit patent grant, and compatible with the npm ecosystem used here. |
| Lean proofs (`formal/`) | **Apache-2.0** | Lean 4 core and Mathlib are Apache-2.0, so formal contributions can move between the projects without friction. |
| Python experiments (`compute/`) | **Apache-2.0** | Code. SymPy (BSD), NumPy (BSD) and Pyodide (MPL-2.0, used unmodified from its CDN) are compatible. |
| Educational content: lesson text, exercises, solutions, trail text, diagrams, glossaries, registries | **CC BY-SA 4.0** (`LICENSE-CONTENT`) | Lets anyone translate, adapt and redistribute the material, including commercially, as long as adaptations stay open. It is the licence used by Wikipedia, which makes reuse in both directions easier. |

## Notes

- **Mixed files.** MDX lessons contain both prose (CC BY-SA 4.0) and small code snippets. Code embedded in lessons is offered under both licences, so it can be reused as software.
- **Third-party fonts** (Inter, Source Serif 4, JetBrains Mono, Noto) are under the SIL Open Font License and are self-hosted by `next/font` at build time.
- **KaTeX** (MIT), **Shiki** (MIT), **lucide** icons (ISC), **Next.js/React** (MIT) and **Tailwind CSS** (MIT) are all compatible with Apache-2.0 distribution.
- **Quotations** from scripture in optional reflections are short and attributed.
- This is a proposal. Before the project accepts outside contributions it should adopt a contributor agreement or a Developer Certificate of Origin, and have the dual-licensing of embedded snippets reviewed by someone qualified.
