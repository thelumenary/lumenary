<Section id="motivation" kind="motivation" title="One late bus">

A transport official in Kampala announces: “**Every** bus on Route 7 arrived on time today.” Nadia waited twenty minutes for hers. What exactly does she need to show to prove the announcement false? Not that *no* bus was on time — just that **at least one** bus was late.

Now compare two sentences about a village in the Swiss Alps:

- “Everyone in the village has someone they can ask for help.”
- “There is someone in the village whom everyone can ask for help.”

They use the same words, in a different order, and say very different things. The first could be true because neighbours help each other; the second needs one remarkable person.

And here is a bigger question: how many natural numbers are there? “Infinitely many,” you might say. But what does that mean — and how could anyone be *sure*, without checking them all?

This lesson gives you the precise language for all three questions: sets described by rules, the words **for all** and **there exists**, and **infinite sets**.

</Section>

<Section id="intuition" kind="intuition" title="Rules, checks and searches">

A set can be given by a **list** of its elements, like $\{2, 4, 6\}$, or by a **rule** that says which elements belong. Think of a door with a doorkeeper: you name the crowd waiting outside (“the natural numbers”), and the doorkeeper lets in exactly those who pass a test (“is even”). Rules can describe sets far too large to list, such as all the even numbers.

Statements about *all* members and *some* members of a set behave like checks and searches:

- “**Every** element has the property” is a **check**: it is true only if every single element passes. One failure makes it false.
- “**Some** element has the property” is a **search**: it is true as soon as one element passes. It is false only if every element fails.

On a small set such as $\{1, 2, 3\}$, “every element has property $P$” just means “$P(1)$ **and** $P(2)$ **and** $P(3)$”, while “some element has $P$” means “$P(1)$ **or** $P(2)$ **or** $P(3)$”. Denying a long “and” gives a long “or” of denials — which is exactly why one late bus is enough.

<Narrator who="chloe">

Here's a game that makes the order of “for all” and “there exists” vivid. To win “for every $x$ there is a $y$ with $y > x$”, a sceptic names any natural number $x$ and you answer with a bigger $y$ — easy: answer $x + 1$. To win “there is a $y$ such that for every $x$, $y > x$”, **you** must name your $y$ first, and then the sceptic picks $x$. The sceptic just picks $x = y$, and you lose. Who moves first changes everything.

</Narrator>

</Section>

<Section id="definitions" kind="definitions" title="Definitions and notation">

Throughout, $\N = \{0, 1, 2, 3, \dots\}$ is the set of natural numbers and $\Z$ the set of integers.

<Definition term="set-builder notation">

If $A$ is a set and $P(x)$ is a statement about $x$, then

$$
\{\, x \in A : P(x) \,\}
$$

is the set of those elements $x$ of $A$ for which $P(x)$ is true. Read it as “the set of $x$ in $A$ such that $P(x)$”. (Many books write a vertical bar instead of the colon: $\{x \in A \mid P(x)\}$.)

</Definition>

A second form describes a set by a **formula** for its elements: $\{\, 2k : k \in \N \,\}$ is the set of all numbers $2k$ with $k$ a natural number, that is $\{0, 2, 4, 6, \dots\}$.

The letter in set-builder notation is a placeholder: $\{x \in \N : x < 3\}$ and $\{n \in \N : n < 3\}$ are the same set, $\{0, 1, 2\}$.

<Definition term="quantifiers">

Let $A$ be a set and $P(x)$ a statement about $x$.

- $\forall x \in A,\ P(x)$ means: **for every** $x$ in $A$, $P(x)$ is true. The symbol $\forall$ (an upside-down A, for “all”) is the **universal quantifier**.
- $\exists x \in A,\ P(x)$ means: **there exists** at least one $x$ in $A$ for which $P(x)$ is true. The symbol $\exists$ (a backwards E, for “exists”) is the **existential quantifier**.

</Definition>

“There exists” means **at least one**, not exactly one: $\exists n \in \N,\ n > 5$ is true, with many witnesses. On its own, a statement such as “$x > 5$” is neither true nor false — it becomes true or false once we say what $x$ is, or quantify it.

<Definition term="finite and infinite sets">

A set is **finite** if its elements can be listed as $a_1, a_2, \dots, a_n$ for some natural number $n$ (with $n = 0$ for the empty set). Otherwise it is **infinite**.

</Definition>

</Section>

<Section id="examples" kind="examples" title="Worked examples">

<Example title="Reading set-builder notation">

- $\{n \in \N : n \text{ is even}\} = \{0, 2, 4, 6, \dots\} = \{2k : k \in \N\}$ — two descriptions of the same set.
- $\{x \in \Z : x^2 < 10\} = \{-3, -2, -1, 0, 1, 2, 3\}$, because $3^2 = 9 < 10$ but $4^2 = 16$.
- $\{p \in \N : p \text{ is prime and } p < 20\} = \{2, 3, 5, 7, 11, 13, 17, 19\}$.
- $\{n \in \N : n < 0\} = \varnothing$: no natural number passes the test.
- The set in front of the colon matters: $\{x \in \Z : 2x = 7\} = \varnothing$, but $\{x \in \Q : 2x = 7\} = \{\tfrac{7}{2}\}$.

</Example>

<Example title="Translating sentences">

| Sentence | In symbols |
| --- | --- |
| The square of every integer is at least $0$. | $\forall n \in \Z,\ n^2 \ge 0$ |
| Some prime number is even. | $\exists p \in \N,\ p \text{ is prime and } p \text{ is even}$ |
| No odd number is a multiple of $2$. | $\neg\, \exists n \in \N,\ n \text{ is odd and } n \text{ is a multiple of } 2$ |
| Every integer has an opposite. | $\forall x \in \Z,\ \exists y \in \Z,\ x + y = 0$ |
| Some integer is the opposite of every integer. | $\exists y \in \Z,\ \forall x \in \Z,\ x + y = 0$ |

The symbol $\neg$ means “not”. The last two rows use the same pieces in a different order; the first is true and the second is false.

</Example>

<Example title="Negating, step by step">

To deny a statement, swap $\forall$ and $\exists$ and deny what follows.

- “Every bus was on time” becomes “**some** bus was **not** on time”.
- “Some student in the class has a pet snake” becomes “**every** student in the class does **not** have a pet snake”, that is, “no student has a pet snake”.
- “For every natural number $n$, $n^2 + n + 41$ is prime” becomes “there is a natural number $n$ for which $n^2 + n + 41$ is **not** prime”. The denial is the true one: at $n = 40$ we get $1681 = 41 \cdot 41$.
- With two quantifiers, apply the rule twice: “$\forall x\ \exists y,\ x + y = 0$” becomes “$\exists x\ \forall y,\ x + y \neq 0$” — “some integer has no opposite”.

</Example>

</Section>

<Section id="proof" kind="proof" title="The rules, proved">

In this section $A$ is any set and $P(x)$ any statement about elements of $A$.

<Theorem name="Theorem 1 (negating quantifiers)">

(a) “Not every $x \in A$ has $P$” is equivalent to “some $x \in A$ does not have $P$”:

$$
\neg\, \big(\forall x \in A,\ P(x)\big) \iff \exists x \in A,\ \neg P(x).
$$

(b) “No $x \in A$ has $P$” is equivalent to “every $x \in A$ fails $P$”:

$$
\neg\, \big(\exists x \in A,\ P(x)\big) \iff \forall x \in A,\ \neg P(x).
$$

</Theorem>

<Proof>

We prove (b) first.

($\Rightarrow$) Suppose no element of $A$ has $P$, and take any $x \in A$. If $P(x)$ were true, $x$ would be an element with $P$, which is impossible. So $\neg P(x)$.

($\Leftarrow$) Suppose every element fails $P$. If some $x$ had $P$, it would both have and fail $P$. So no element has $P$.

Now (a).

($\Leftarrow$) If some $x$ does not have $P$, then $x$ is a counterexample to “every element has $P$”, so that statement is false.

($\Rightarrow$) Suppose not every element has $P$, and assume, for contradiction, that **no** element fails $P$. By (b), applied to the statement “$x$ fails $P$”, every element does not fail $P$ — that is, every element has $P$. That contradicts our assumption. So some element fails $P$.

</Proof>

The last step used the principle that “not failing $P$” means “having $P$”. Every statement is either true or false — the **law of excluded middle**. Almost all of mathematics uses it freely; the logic viewpoint below explains who doesn't, and why.

<Theorem name="Theorem 2 (the order of quantifiers matters)">

In $\N$, the statement $\forall x\ \exists y,\ y > x$ is true, but $\exists y\ \forall x,\ y > x$ is false.

</Theorem>

<Proof>

*The first is true.* Let $x$ be any natural number. Then $y = x + 1$ is a natural number with $y > x$.

*The second is false.* Suppose some $y$ satisfied $y > x$ for every natural number $x$. Taking $x = y$ gives $y > y$, which is impossible.

</Proof>

In the first statement $y$ may **depend on** $x$ (we chose $y = x + 1$). In the second, one single $y$ must work for every $x$ at once. In general, “$\exists y\ \forall x$” implies “$\forall x\ \exists y$” — the one $y$ that works for everybody works for each $x$ — but not the other way round.

<Theorem name="Theorem 3 (vacuous truth)">

For every property $P$, the statement $\forall x \in \varnothing,\ P(x)$ is true, and $\exists x \in \varnothing,\ P(x)$ is false.

</Theorem>

<Proof>

By Theorem 1(a), the denial of “$\forall x \in \varnothing,\ P(x)$” is “there is an $x \in \varnothing$ with $\neg P(x)$”. That would need an element of the empty set, and there is none. So the denial is false and the statement is true. Similarly, “$\exists x \in \varnothing,\ P(x)$” needs an element of $\varnothing$, so it is false.

</Proof>

So “every element of the empty set is even” and “every element of the empty set is odd” are **both** true. They do not contradict each other, because there is nothing that would have to be even and odd at once.

<Theorem name="Theorem 4 (ℕ is infinite)">

For every finite list $a_1, \dots, a_n$ of natural numbers there is a natural number that is not on the list. So $\N$ is infinite.

</Theorem>

<Proof>

If the list is empty, $0$ is not on it. Otherwise let $M$ be the largest number on the list. Then $M + 1$ is a natural number, and for every $i$ we have $a_i \le M < M + 1$, so $a_i \neq M + 1$. So $M + 1$ is not on the list.

Therefore no finite list contains all of $\N$: by definition, $\N$ is infinite.

</Proof>

Look at the quantifiers: *for every* list *there exists* a missing number, and the missing number depends on the list. The swapped statement — “there is a number missing from every finite list” — is false, because whatever number $m$ you pick, the one-item list $m$ contains it.

<Theorem name="Theorem 5 (the even numbers are infinite)">

For every finite list of natural numbers there is an **even** number that is not on it.

</Theorem>

<Proof>

If the list is empty, $0$ is missing. Otherwise let $M$ be its largest number. Then $2(M + 1)$ is even, and $2(M + 1) \ge M + 1 > M$, so it is bigger than every number on the list and cannot be on it.

</Proof>

<Note>

**Infinity is not a natural number.** If there were a largest natural number — call it $\infty$ — then $\infty + 1$ would be a natural number larger still. Theorem 2 says exactly that there is no largest natural number. “$\N$ is infinite” is a statement about the *set* $\N$ (it cannot be listed), not about some enormous number inside it. Euclid proved the same kind of fact about primes around 300 BCE: given any finite list of primes, multiplying them and adding $1$ gives a number whose prime factors are all missing from the list (*Elements*, Book IX, Proposition 20; see <TopicLink id="math.number.factors-primes">factors and primes</TopicLink>).

</Note>

</Section>

<Section id="misconceptions" kind="misconceptions" title="Common misconceptions">

<Misconception>

**“Swapping $\forall$ and $\exists$ doesn't change the meaning.”** “Everyone has someone they can ask for help” ($\forall x\ \exists y$) is different from “someone can be asked for help by everyone” ($\exists y\ \forall x$). In $\N$, $\forall x\ \exists y,\ y > x$ is true and $\exists y\ \forall x,\ y > x$ is false. Read quantifiers from left to right, and remember that each one may depend on those before it.

</Misconception>

<Misconception>

**“The denial of ‘every $x$ has $P$’ is ‘no $x$ has $P$’.”** To deny “every bus was on time” you need only one late bus. The correct denial is “**some** $x$ does **not** have $P$”. “No bus was on time” is a much stronger claim.

</Misconception>

<Misconception>

**“A statement about every element of the empty set must be false — or meaningless.”** It is true, because its denial would need an element of the empty set. This is not a trick: it is what makes rules like “a set with no elements is a subset of every set” work, and Python agrees — `all([])` is `True`.

</Misconception>

<Misconception>

**“Infinity is a very large natural number.”** Every natural number $n$ is followed by a larger one, $n + 1$, so no natural number is “the last one”. “Infinite” describes the whole set $\N$: it cannot be written as a finite list.

</Misconception>

<Misconception>

**“Checking a million cases proves a ‘for all’ statement.”** It can make the statement very believable, and one failure would refute it — but $n^2 + n + 41$ is prime for $n = 0, 1, \dots, 39$ and fails at $n = 40$. A statement about infinitely many numbers needs a proof.

</Misconception>

<Section id="viewpoints" kind="viewpoints" title="Other ways of seeing">

<Viewpoint lens="logic" title="Games, and the logicians who disagree">

Logicians make the sceptic game from the intuition section precise: a quantified statement is true exactly when its defender has a **winning strategy** in a game where $\forall$ is the sceptic's move and $\exists$ is the defender's. A strategy for “$\forall x\ \exists y$” is a *rule* for choosing $y$ from $x$, such as $y = x + 1$. This **game semantics** was developed by Jaakko Hintikka and others in the 20th century.

Not every mathematician accepts every rule in this lesson. **Constructive** mathematicians, following L. E. J. Brouwer, accept “$\exists x,\ P(x)$” only when one can actually produce such an $x$. They accept three of the four directions in Theorem 1, but not “not every $x$ has $P$, therefore some $x$ fails $P$” for infinite sets — knowing that a universal statement is false does not, by itself, hand you a counterexample. Lean can work both ways, and marks the classical step explicitly (see the formal section). Quantifiers become part of a fully formal language in <TopicLink id="math.found.first-order-logic">first-order logic</TopicLink>.

</Viewpoint>

<Viewpoint lens="sets" title="Why the “∈ A” matters">

Set-builder notation always says where to look: $\{x \in A : P(x)\}$, not just $\{x : P(x)\}$. This is not fussiness. In 1901 Bertrand Russell showed that the unrestricted rule “the set of all $x$ with $P(x)$” leads to a contradiction when $P(x)$ is “$x$ is not a member of itself” (see <TopicLink id="math.found.russell-paradox">Russell's paradox</TopicLink>). Modern set theory allows only the restricted form — picking out elements of a set you already have — and that rule, called the axiom of separation, is safe.

</Viewpoint>

<Viewpoint lens="analysis" title="Every ε has an N">

Calculus is written in quantifiers. “The numbers $1, \tfrac{1}{2}, \tfrac{1}{3}, \dots$ get as close to $0$ as you like” means: for every distance $\varepsilon > 0$ there is a position $N$ such that every term after the $N$-th is within $\varepsilon$ of $0$,

$$
\forall \varepsilon > 0\ \ \exists N \in \N\ \ \forall n > N,\ \ \tfrac{1}{n} < \varepsilon.
$$

Here $N$ depends on $\varepsilon$: for $\varepsilon = 0.01$ we can take $N = 100$. Swapping the first two quantifiers would claim one $N$ that works for every $\varepsilon$ — false, since no term $\tfrac{1}{n}$ is below *every* positive $\varepsilon$. The difference between “continuous” and “uniformly continuous”, later on, is exactly such a swap (see <TopicLink id="math.analysis.sequences-series">sequences and series</TopicLink>).

</Viewpoint>

<Viewpoint lens="computation" title="Searching can refute, but never confirm">

A computer can search for a counterexample to a “for all” statement, and if it finds one, the statement is refuted for good. If the search finds nothing, the statement might still fail further on. Goldbach's conjecture (1742) — every even number greater than $2$ is the sum of two primes — has been checked by computer for every even number up to $4 \times 10^{18}$ (Oliveira e Silva, Herzog and Pardi, 2014), and it is still unproved. On a finite set, though, checking every case *is* a proof, which is how Lean's `decide` works (see <TopicLink id="math.comp.programming-intro">programming for mathematics</TopicLink>).

</Viewpoint>

<Section id="history" kind="history" title="History and global context">

- **Aristotle** (Athens, 4th century BCE) studied the four forms “every A is B”, “no A is B”, “some A is B” and “some A is not B”, and how they deny one another — later drawn as the *square of opposition*.
- **Euclid**'s *Elements* (around 300 BCE) states that “prime numbers are more than any assigned multitude of prime numbers” (Book IX, Proposition 20) — a statement about every finite list, proved exactly in the style of Theorem 4.
- Jaina mathematicians in ancient India classified numbers as enumerable, innumerable and infinite, and distinguished several kinds of infinity (described in G. G. Joseph's *The Crest of the Peacock*).
- **Galileo Galilei**, in *Two New Sciences* (1638), noticed that the perfect squares can be paired off with all the natural numbers, although most numbers are not squares — a puzzle about infinite sets that **Georg Cantor** resolved in the 1870s–1890s by taking such pairings as the definition of “same size” (see <TopicLink id="math.found.countability">countability</TopicLink>).
- Quantifiers as symbols came with modern logic: **Gottlob Frege**'s *Begriffsschrift* (1879) and, independently, **Charles Sanders Peirce** (1885). The symbol $\exists$ was introduced by **Giuseppe Peano** (1897), and $\forall$ by **Gerhard Gentzen** (1935).

</Section>
