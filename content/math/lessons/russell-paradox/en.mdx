<Section id="motivation" kind="motivation" title="The barber">

In a certain village there is a barber who shaves **exactly** those villagers who do not shave themselves. Who shaves the barber?

If the barber shaves himself, then he is one of the people who shave themselves — and the barber shaves none of those. So he does not shave himself. But then he is one of the people who do not shave themselves — and the barber shaves all of those. So he does shave himself. Either way we are stuck.

The way out is simple: **there is no such village.** The description "a barber who shaves exactly those who do not shave themselves" describes nobody, just as "a square circle" describes nothing.

That would be a mere puzzle, except for what happened in 1901. Bertrand Russell noticed that the same reasoning applies to a principle about sets that mathematicians had been using freely — and that Gottlob Frege had made a cornerstone of his attempt to build all of mathematics on logic. Russell himself later used the barber, in lectures given in 1918, as a popular illustration of his discovery. This lesson tells what he found, and how mathematics recovered.

</Section>

<Section id="intuition" kind="intuition" title="Every property, a set?">

We describe sets by properties all the time: $\{n \in \N : n \text{ is even}\}$, the set of solutions of an equation, the set of points at distance $1$ from the origin. It is tempting to believe that **any** property defines a set — the set of all things having that property.

Sets can be elements of other sets: $\{\{1, 2\}, \{3\}\}$ has two elements, each a set. So we can ask of a set $x$ whether it is an element of *itself*, $x \in x$. For familiar sets the answer is no: the set of all triangles is not a triangle, and $\{1, 2\}$ is not an element of $\{1, 2\}$. But if every property defined a set, there would be a set of *all* sets, and it would be an element of itself.

Now consider the property "**$x$ is not an element of itself**". It looks harmless; most sets have it. What could go wrong with the set of all of them?

<Narrator who="chloe">

Before reading on, try it yourself: call that set $R$, and ask whether $R$ is an element of $R$. You will find yourself in the barber's shop.

</Narrator>

</Section>

<Section id="definitions" kind="definitions" title="Definitions">

<Definition term="naive comprehension">

**Naive comprehension** is the principle: for every property $P$ there is a set $\{x : P(x)\}$ whose elements are exactly the objects $x$ with $P(x)$.

</Definition>

<Definition term="Russell's set">

**Russell's set** is the set that naive comprehension would give for the property "$x \notin x$":

$$
R = \{x : x \notin x\}.
$$

</Definition>

<Definition term="separation">

The **separation axiom** (also called *specification*): for every set $A$ and every property $P$, there is a set

$$
\{x \in A : P(x)\}
$$

whose elements are exactly the elements $x$ **of $A$** with $P(x)$.

</Definition>

Separation looks like a cautious version of comprehension: it only carves subsets out of a set we already have. As we shall see, that caution is exactly what is needed. A collection described by a property, which may or may not be a set, is informally called a **class**.

</Section>

<Section id="proof" kind="proof" title="The paradox and the cure">

At the heart of everything is a tiny fact of logic.

<Theorem name="Lemma 1">

No statement $p$ is equivalent to its own negation: it is never the case that $p \leftrightarrow \neg p$.

</Theorem>

<Proof>

Suppose $p \leftrightarrow \neg p$. If $p$ were true, then $\neg p$ would be true as well — impossible; so $p$ is false, that is, $\neg p$ holds. But then, by the equivalence, $p$ holds. This is a contradiction.

</Proof>

In truth-table terms, $p \leftrightarrow \neg p$ is false in both rows: it is a **contradiction**. (You can check this in the explorer below.)

<Theorem name="Theorem 2 (Russell's theorem — pure logic)">

Let $E$ be **any** relation on **any** collection of objects. Then there is no object $r$ such that, for every object $x$,

$$
x \mathrel{E} r \iff \text{not } (x \mathrel{E} x).
$$

</Theorem>

<Proof>

Suppose there were such an $r$. The condition holds for every $x$, in particular for $x = r$: $\; r \mathrel{E} r \iff \text{not } (r \mathrel{E} r)$. This contradicts Lemma 1.

</Proof>

That is the whole argument. Its strength is its generality: it does not matter what the objects are or what $E$ means.

- If the objects are villagers and $x \mathrel{E} y$ means "$y$ shaves $x$", Theorem 2 says no villager $r$ shaves exactly those who do not shave themselves: **there is no such barber**.
- If the objects are sets and $x \mathrel{E} y$ means $x \in y$, Theorem 2 says that **no set $R$ has as its elements exactly the sets that are not elements of themselves**.

<Theorem name="Corollary 3 (naive comprehension is inconsistent)">

Naive comprehension leads to a contradiction.

</Theorem>

<Proof>

Naive comprehension, applied to the property $x \notin x$, gives a set $R$ with $x \in R \iff x \notin x$ for every $x$. In particular $R \in R \iff R \notin R$, which Theorem 2 forbids.

</Proof>

So naive comprehension cannot be part of a consistent theory of sets: a theory that proves a contradiction proves everything, and is useless. What should replace it?

<Theorem name="Theorem 4 (separation blocks the paradox)">

Assume the separation axiom. For every set $A$, the set $R_A = \{x \in A : x \notin x\}$ exists and is **not an element of $A$**.

</Theorem>

<Proof>

$R_A$ exists by separation, and for every $x$:

$$
x \in R_A \iff x \in A \text{ and } x \notin x .
$$

Suppose $R_A \in A$. Taking $x = R_A$, the condition "$x \in A$" is true, so the line above becomes $R_A \in R_A \iff R_A \notin R_A$ — a contradiction with Lemma 1. Hence $R_A \notin A$.

</Proof>

Notice what changed. Naive comprehension forced the Russell set to exist *and* to be one of the things it was talking about. Separation lets us build the Russell set *inside* $A$ — and the argument, instead of a contradiction, now proves a theorem: $R_A$ is something outside $A$.

<Theorem name="Corollary 5 (there is no set of all sets)">

Assuming separation, no set $U$ contains every set as an element.

</Theorem>

<Proof>

If $U$ contained every set, it would contain $R_U = \{x \in U : x \notin x\}$, which exists by separation. Theorem 4 says $R_U \notin U$.

</Proof>

The collection of all sets is a perfectly good *class*, but it is too big to be a set. Halmos summed this up in his textbook as "nothing contains everything".

<Theorem name="Theorem 6 (Cantor's theorem is the same argument)">

For every set $A$, no function $f : A \to \mathcal{P}(A)$ is surjective.

</Theorem>

<Proof>

Define a relation on $A$ by $x \mathrel{E} y \iff x \in f(y)$. If $f$ were surjective, some $r \in A$ would satisfy $f(r) = \{x \in A : x \notin f(x)\}$, that is, $x \mathrel{E} r \iff \text{not } (x \mathrel{E} x)$ for every $x \in A$. Theorem 2 says no such $r$ exists.

</Proof>

This is no coincidence: Russell found his paradox by thinking about Cantor's proof that there is no largest set (see <TopicLink id="math.found.countability">countability</TopicLink>). If there were a set $U$ of all sets, then $\mathcal{P}(U) \subseteq U$, so $U$ would be at least as large as its own power set — contradicting Cantor's theorem. Following Cantor's diagonal set for this situation leads straight to Russell's set.

<Section id="axioms" kind="human" title="How axioms rescue set theory">

After Russell's discovery mathematicians took two main routes.

**Ernst Zermelo** (1908) listed explicit axioms saying which sets exist, with separation in place of comprehension. With later additions by Abraham Fraenkel and Thoralf Skolem (the replacement axiom, 1922) and the axiom of choice, these became **ZFC**, the standard foundation of mathematics today. Informally:

| Axiom | What it says |
| --- | --- |
| Extensionality | Sets with the same elements are equal. |
| Empty set | There is a set with no elements. |
| Pairing | For sets $a, b$ there is a set $\{a, b\}$. |
| Union | For every set of sets, there is a set of all their elements. |
| Power set | For every set $A$, there is the set $\mathcal{P}(A)$ of its subsets. |
| Infinity | There is an infinite set (one containing $\varnothing$, $\{\varnothing\}$, …). |
| Separation | For a set $A$ and a property $P$, there is $\{x \in A : P(x)\}$. |
| Replacement | The image of a set under a definable rule is a set. |
| Foundation | Every non-empty set has an element sharing no elements with it. |
| Choice | Every set of non-empty sets has a choice function. |

Every set that ordinary mathematics needs — $\N$, $\R$, the set of continuous functions, $\{x \in \R : x^2 < 2\}$ — is built from these, and separation is always applied inside a set we already have. The details are in <TopicLink id="math.found.zfc">ZFC</TopicLink>.

**Russell** himself took a different route: the **theory of types** (1908), developed with Alfred North Whitehead in *Principia Mathematica* (1910–1913). Objects come in levels — individuals, sets of individuals, sets of sets of individuals, … — and a set may only contain objects of the level just below. Then "$x \in x$" is not false but *meaningless*, so the Russell set cannot even be described. Modern type theories, including the one behind the Lean proof assistant, descend in part from this idea; see <TopicLink id="math.found.type-theory">type theory</TopicLink>.

Other approaches exist too. Von Neumann–Bernays–Gödel set theory speaks officially about classes, and calls those too big to be sets *proper classes*; Willard Van Orman Quine's *New Foundations* (1937) restricts comprehension in another way and, remarkably, does contain a universal set.

<Note>

**Naive set theory is still useful.** Mathematicians use the everyday language of sets — "the set of all $x$ such that…" — all the time, with the understanding that $x$ ranges over some set already at hand. The axioms are the guarantee that this everyday language can be made precise without contradiction.

</Note>

</Section>

<Section id="misconceptions" kind="misconceptions" title="Common misconceptions">

<Misconception>

**"Russell's paradox shows that mathematics is inconsistent."** It shows that **naive comprehension** is inconsistent. Set theories that replace it by separation, such as ZFC, have no known contradiction, and all of ordinary mathematics can be developed inside them. (By Gödel's second incompleteness theorem, ZFC cannot prove its own consistency — but that is a different matter from being inconsistent.)

</Misconception>

<Misconception>

**"Russell's paradox is just the liar paradox."** They are analogous — both involve self-reference and a statement equivalent to its own negation — but not identical. The liar ("this sentence is false") is about truth and language; Russell's argument is a valid deduction, in pure logic, from a precise principle about membership. Its conclusion is not a riddle but a theorem: the principle is inconsistent.

</Misconception>

<Misconception>

**"ZF avoids the paradox by banning $x \in x$."** ZF does prove that no set is an element of itself, but from a separate axiom, **foundation**. The paradox is blocked by **separation**: Theorem 4 never uses foundation, and set theories without foundation are still free of Russell's paradox.

</Misconception>

<Misconception>

**"The set $\{x \in A : x \notin x\}$ is forbidden."** It exists for every set $A$, by separation. What is impossible is for it to be an element of $A$ — and for a set of all sets to exist.

</Misconception>

</Section>

<Section id="viewpoints" kind="viewpoints" title="Many ways of seeing">

<Viewpoint lens="logic" title="a theorem about every relation">

Logically, Theorem 2 is the statement $\neg \exists r\, \forall x\, (x \mathrel{E} r \leftrightarrow \neg\, x \mathrel{E} x)$, which is provable in first-order logic for a relation symbol $E$ with no axioms at all — and even in constructive logic. Russell's paradox is therefore not about sets specifically: any theory that postulates, for every property, an object whose "members" are exactly the things with that property, collapses. That is why the cure had to be a change in the *principles of existence*, not in logic.

</Viewpoint>

<Viewpoint lens="categories" title="Lawvere's fixed-point theorem">

In 1969 F. William Lawvere found a single theorem behind Cantor's and Russell's arguments (and, with more work, Gödel's and Tarski's). In a cartesian closed category: if there is a map $\varphi : A \to Y^A$ that is surjective on points, then **every** map $g : Y \to Y$ has a fixed point. For sets, take $Y = \{\text{true}, \text{false}\}$, so that $Y^A \cong \mathcal{P}(A)$, and $g = $ "not", which has no fixed point. Conclusion: there is no surjection $A \to \mathcal{P}(A)$ — Cantor's theorem. The diagonal is the map $a \mapsto g(\varphi(a)(a))$, exactly Russell's "not ($x \in x$)".

</Viewpoint>

<Viewpoint lens="computation" title="the program that asks about itself">

Turing's proof (1936) that no program can decide whether every program halts has Russell's shape. If a program $H$ did, build a program $D$ that, given the code of a program $p$, runs $H$ on "$p$ applied to its own code" and does the opposite: loops for ever if $H$ says it halts, and halts if $H$ says it loops. Now run $D$ on its own code. It halts if and only if it does not. So $H$ cannot exist; see <TopicLink id="math.comp.computability">computability</TopicLink>.

</Viewpoint>

<Viewpoint lens="sets" title="the cumulative hierarchy">

The modern picture of the set-theoretic universe explains *why* the axioms are true. Sets are formed in stages: $V_0 = \varnothing$, $V_{n+1} = \mathcal{P}(V_n)$, and onwards through the transfinite. A set is formed only from sets available at earlier stages. In this picture no set can contain itself (it would have to exist before itself), and no set contains everything (there is always a later stage). Separation is safe because $\{x \in A : P(x)\}$ only uses elements of $A$, which are already there.

</Viewpoint>

</Section>

<Section id="history" kind="history" title="History and global context">

- **Self-reference is old.** The liar paradox ("what I am saying now is false") is attributed to Eubulides of Miletus in the 4th century BCE. In China, the Later Mohist canons (around 300 BCE) observed that the claim "all saying is contradictory" contradicts itself. These are cousins of Russell's paradox, not the same argument.
- **Warning signs.** Cesare Burali-Forti (1897) found a contradiction in the idea of the set of all ordinal numbers, and Georg Cantor, in letters to Richard Dedekind (1899), distinguished "consistent multiplicities" (sets) from "inconsistent" ones, such as the totality of everything.
- **Frege and Russell.** Gottlob Frege's *Basic Laws of Arithmetic* (volume 1, 1893) derived arithmetic from logic using a principle (his Basic Law V) that implies naive comprehension. Bertrand Russell discovered the contradiction in 1901 while studying Cantor's proof that there is no largest cardinal, and wrote to Frege on 16 June 1902, as volume 2 was going to press. Frege replied within days that it had shaken the basis on which he intended to build arithmetic, and added an appendix about it to volume 2 (1903). Ernst Zermelo had found the same contradiction independently, around 1900, but did not publish it.
- **Repairs.** Russell's theory of types (1908) and *Principia Mathematica* with Alfred North Whitehead (1910–1913); Zermelo's axioms (1908); replacement, added by Abraham Fraenkel and Thoralf Skolem (1922); John von Neumann's treatment of classes (1925). Together these shaped the foundations used today.
