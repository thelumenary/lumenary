<Section id="motivation" kind="motivation" title="One input, one output">

Every student in a school has exactly one birth month. A vending machine gives exactly one snack for each button that works. A thermometer shows exactly one temperature at each moment.

Each of these is a **rule** that takes something in and gives **exactly one** thing out. Rules like this are everywhere: in science, in economics, in computer programs, and in every branch of mathematics. They are called **functions**.

</Section>

<Section id="definitions" kind="definitions" title="What a function is">

<Definition term="function">

A **function** $f$ from a set $A$ to a set $B$, written $f : A \to B$, assigns to **every** element $a \in A$ **exactly one** element $f(a) \in B$.

</Definition>

- $A$ is the **domain** — the allowed inputs.
- $B$ is the **codomain** — where the outputs are allowed to live.
- The **image** $f(A) = \{\, f(a) \mid a \in A \,\}$ is the set of outputs that actually occur. It is a subset of the codomain, but it need not be all of it.

Two conditions hide in the definition, and both matter:

1. **Every** input has an output — nothing in $A$ is left out.
2. Each input has **exactly one** output — no input is sent to two places.

</Section>

<Section id="examples" kind="examples" title="Examples and non-examples">

<Example title="Functions">

- $f : \Z \to \Z$, $f(n) = 2n + 1$. Every integer has exactly one output; the image is the set of odd integers.
- $s : \Z \to \Z$, $s(n) = n^2$. The image is $\{0, 1, 4, 9, \dots\}$, which is smaller than the codomain $\Z$.
- The rule sending each student to their birth month is a function from the set of students to the set of twelve months.

</Example>

<Example title="Not functions">

- "Send each person to their sibling" is not a function from people to people: some people have several siblings, and some have none.
- "Send each integer $n$ to a number whose square is $n$" fails twice: $4$ has two square roots, $2$ and $-2$, and $-1$ has none in $\Z$.

</Example>

</Section>

<Section id="properties" kind="definitions" title="Injective, surjective, bijective">

<Definition term="injective (one-to-one)">

$f : A \to B$ is **injective** if different inputs always give different outputs: whenever $f(x) = f(y)$, we have $x = y$.

</Definition>

<Definition term="surjective (onto)">

$f : A \to B$ is **surjective** if every element of the codomain is an output: for every $b \in B$ there is some $a \in A$ with $f(a) = b$.

</Definition>

<Definition term="bijective">

$f$ is **bijective** if it is both injective and surjective. A bijection pairs the elements of $A$ and $B$ perfectly, so it can be reversed.

</Definition>

Surjectivity depends on the codomain you choose. $s(n) = n^2$ is not surjective as a function $\Z \to \Z$, but it *is* surjective onto its image $\{0, 1, 4, 9, \dots\}$.

</Section>

<Section id="proofs" kind="proof" title="Proving the properties">

<Theorem name="injective">

$f : \Z \to \Z$, $f(n) = 2n + 1$, is injective.

</Theorem>

<Proof>

Suppose $f(x) = f(y)$, that is, $2x + 1 = 2y + 1$. Subtracting $1$ gives $2x = 2y$, and dividing by $2$ gives $x = y$.

</Proof>

<Theorem name="not injective">

$s : \Z \to \Z$, $s(n) = n^2$, is not injective.

</Theorem>

<Proof>

One counterexample is enough: $s(1) = 1 = s(-1)$, but $1 \neq -1$.

</Proof>

<Theorem name="not surjective">

$d : \Z \to \Z$, $d(n) = 2n$, is not surjective.

</Theorem>

<Proof>

Every output $2n$ is even, so the odd number $1$ is never an output.

</Proof>

<Narrator who="gideon">

Look at the shapes of these proofs. To show a function **is** injective, we take *arbitrary* $x$ and $y$ and reason in general. To show it is **not**, a single counterexample suffices. "For all" claims need arguments; "there exists" claims need examples.

</Narrator>

</Section>

<Section id="sets" kind="sets" title="A function is a set of ordered pairs">

In set theory, a function is not a "machine" or a "formula" — it is a set. The **graph** of $f : A \to B$ is

$$
\Gamma_f = \{\, (a, f(a)) \mid a \in A \,\} \subseteq A \times B.
$$

A subset $R \subseteq A \times B$ is the graph of a function exactly when **each $a \in A$ appears as the first coordinate of exactly one pair** in $R$. That is the definition of a function used throughout modern mathematics: it is precise, and it doesn't care whether the rule has a formula.

</Note>

</Section>

<Section id="computation" kind="computation" title="How many functions are there?">

If $|A| = m$ and $|B| = n$, each of the $m$ inputs independently chooses one of $n$ outputs, so there are $n^m$ functions $A \to B$. Injective functions are rarer: the first input has $n$ choices, the next $n - 1$, and so on, giving $n(n-1)\cdots(n-m+1)$.

<Section id="misconceptions" kind="misconceptions" title="Common misconceptions">

<Misconception>

**"A function must have a formula."** The birth-month function has no formula. A function is any rule — or any set of pairs — giving exactly one output per input.

</Misconception>

<Misconception>

**"The codomain is the same as the image."** The codomain is where outputs are *allowed* to be; the image is where they *actually* are. Whether $f$ is surjective is precisely the question of whether they coincide.

</Misconception>

<Misconception>

**"Exactly one output means exactly one input."** A function may send many inputs to the same output ($n^2$ does). That is allowed; it just means the function is not injective.

</Misconception>

<Misconception>

**"$f(a + b) = f(a) + f(b)$ for every function."** True for $f(n) = 3n$, false for $f(n) = n^2$ or $f(n) = n + 1$. Functions that respect addition are special — they are called *homomorphisms*.

</Misconception>

</Section>

<Section id="categories" kind="categories" title="Functions as arrows">

Arrow diagrams are more than a teaching picture. In much of modern mathematics, structures are studied through the **arrows** between them — functions between sets, structure-preserving maps between groups, continuous maps between spaces. The crucial operation on arrows is following one arrow and then another: **composition**, the subject of the next lesson.

</Section>

<Section id="history" kind="history" title="History and global context">

- Tables recording how one quantity depends on another are ancient. In India, Āryabhaṭa's *Āryabhaṭīya* (499 CE) includes a table for computing sines, and astronomers in many cultures tabulated the positions of the Sun, Moon and planets over time.
- In the 14th century, Nicole Oresme drew diagrams showing how a quality varies with another quantity — an early ancestor of the graph.
- Gottfried Wilhelm Leibniz used the word *function* in the late 17th century; Leonhard Euler introduced the notation $f(x)$ in 1734. In 1837 Peter Gustav Lejeune Dirichlet described functions as arbitrary correspondences, not necessarily given by formulas.
- In the early 20th century, mathematicians began defining functions as sets of ordered pairs, the definition used in this lesson.

</Section>
