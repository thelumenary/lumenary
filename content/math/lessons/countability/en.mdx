<Section id="motivation" kind="motivation" title="The hotel with infinitely many rooms">

Imagine a hotel with rooms numbered $0, 1, 2, 3, \dots$ — one for every natural number — and every room is occupied. A traveller arrives. Is there room?

Yes: ask every guest to move from room $n$ to room $n + 1$. Room $0$ is now free. Now a coach arrives with infinitely many travellers, numbered $0, 1, 2, \dots$ Still no problem: move each guest from room $n$ to room $2n$, freeing all the odd-numbered rooms, and put traveller $k$ in room $2k + 1$.

This thought experiment is usually credited to David Hilbert, in a lecture of 1924, and was made famous by George Gamow's book *One Two Three… Infinity* (1947). It raises a serious question: **is every infinite crowd the same size?** Could *any* infinite collection of travellers be fitted into the hotel? In this lesson we shall see that the answer is no — and prove it with one of the most beautiful arguments in mathematics.

</Section>

<Section id="intuition" kind="intuition" title="Counting is matching">

Long before anyone wrote numerals, a herder could check that every animal had come home by matching animals with pebbles in a bag. Two collections have the same size when their members can be **paired off perfectly**, with nothing left over on either side. Counting a finite set is just matching it with $\{1, 2, \dots, n\}$.

For infinite sets, matching gives surprises. In 1638 Galileo Galilei noticed that the squares $1, 4, 9, 16, \dots$ can be matched with all the counting numbers $1, 2, 3, 4, \dots$ by $n \leftrightarrow n^2$ — even though most counting numbers are not squares. Galileo concluded that "equal", "greater" and "less" do not apply to infinite quantities. Two and a half centuries later Georg Cantor made the opposite, bold choice: *define* "same size" by perfect matching, and accept that a part can be as large as the whole. The rest of this lesson follows Cantor.

<Narrator who="chloe">

So "infinite" is not one size — or is it? Watch for the moment when a matching becomes *impossible*, not just hard to find. That is where the real mathematics is.

</Narrator>

</Section>

<Section id="definitions" kind="definitions" title="Definitions">

We use $\N = \{0, 1, 2, \dots\}$ and the language of <TopicLink id="math.found.functions">functions</TopicLink>: injective, surjective, bijective.

<Definition term="same cardinality">

Sets $A$ and $B$ have the **same cardinality**, written $|A| = |B|$, if there is a bijection $A \to B$. We write $|A| \le |B|$ if there is an injection $A \to B$, and $|A| < |B|$ if $|A| \le |B|$ but $|A| \ne |B|$.

</Definition>

<Definition term="countable, uncountable">

A set is **countably infinite** if it has the same cardinality as $\N$, and **countable** if it is finite or countably infinite. A set that is not countable is **uncountable**.

</Definition>

A countably infinite set is one whose elements can be arranged in an infinite list $a_0, a_1, a_2, \dots$ in which every element appears exactly once. It is often easier to allow repetitions:

<Theorem name="Lemma 1 (lists with repetitions are enough)">

(a) Every subset of $\N$ is countable. (b) If there is an injection $A \to \N$, then $A$ is countable. (c) If $A$ is non-empty and there is a surjection $\N \to A$ — a list $a_0, a_1, a_2, \dots$ in which every element of $A$ appears at least once — then $A$ is countable.

</Theorem>

<Proof>

(a) Let $S \subseteq \N$ be infinite. By the well-ordering principle, let $s_0$ be its least element, $s_1$ the least element of $S \setminus \{s_0\}$, and so on. Then $k \mapsto s_k$ is injective (the $s_k$ increase), and surjective: an element $s \in S$ has only finitely many elements of $S$ below it, say $j$ of them, and then $s = s_j$. (b) An injection $f : A \to \N$ is a bijection from $A$ onto the subset $f(A)$, which is countable by (a). (c) Send each $a \in A$ to the *least* $n$ with $a_n = a$. Different elements get different numbers, so this is an injection $A \to \N$, and (b) applies.

</Proof>

<Definition term="power set">

The **power set** $\mathcal{P}(A)$ of a set $A$ is the set of all subsets of $A$. For example $\mathcal{P}(\{0, 1\}) = \{\varnothing, \{0\}, \{1\}, \{0, 1\}\}$. A finite set with $n$ elements has $2^n$ subsets.

</Definition>

</Section>

<Section id="countable" kind="proof" title="Sets that can be listed">

<Theorem name="Theorem 2 (a part as large as the whole)">

The set $E = \{0, 2, 4, \dots\}$ of even natural numbers has the same cardinality as $\N$.

</Theorem>

<Proof>

The function $n \mapsto 2n$ from $\N$ to $E$ is injective ($2m = 2n$ implies $m = n$) and surjective (every even number is $2n$ for some $n$).

</Proof>

<Theorem name="Theorem 3 (the integers are countable)">

The function $z : \N \to \Z$ given by

$$
z(n) = \begin{cases} n/2 & \text{if } n \text{ is even,} \\ -(n + 1)/2 & \text{if } n \text{ is odd,} \end{cases}
$$

is a bijection. It lists the integers as $0, -1, 1, -2, 2, -3, 3, \dots$

</Theorem>

<Proof>

*Injective.* Even inputs give values $\ge 0$ and odd inputs give values $\le -1$, so two inputs with the same value have the same parity. If both are even, $m/2 = n/2$ gives $m = n$; if both are odd, $-(m+1)/2 = -(n+1)/2$ gives $m = n$.
*Surjective.* An integer $k \ge 0$ equals $z(2k)$, and an integer $k \le -1$ equals $z(-2k - 1)$, where $-2k - 1 \ge 1$ is odd.

</Proof>

<Theorem name="Theorem 4 (pairs of natural numbers are countable)">

Cantor's **pairing function** $\pi : \N \times \N \to \N$,

$$
\pi(m, n) = \frac{(m + n)(m + n + 1)}{2} + n,
$$

is a bijection. Hence $|\N \times \N| = |\N|$.

</Theorem>

<Proof>

Write $T(d) = 0 + 1 + \dots + d = d(d + 1)/2$. The pair $(m, n)$ lies on the diagonal $d = m + n$, and $\pi(m, n) = T(d) + n$ with $0 \le n \le d$. So the values on diagonal $d$ are exactly the $d + 1$ numbers $T(d), T(d) + 1, \dots, T(d) + d$, and the next diagonal starts at $T(d + 1) = T(d) + d + 1$.

*Injective.* If $\pi(m, n) = \pi(m', n')$ with $d = m + n < d' = m' + n'$, then $\pi(m, n) \le T(d) + d < T(d + 1) \le T(d') \le \pi(m', n')$, which is impossible. So $d = d'$; then $T(d) + n = T(d) + n'$ gives $n = n'$, and $m = d - n = m'$.
*Surjective.* The blocks $\{T(d), \dots, T(d) + d\}$ for $d = 0, 1, 2, \dots$ fit together without gaps and cover all of $\N$, so every $k \in \N$ lies in one of them: $k = T(d) + n$ with $0 \le n \le d$, which is $\pi(d - n, n)$.

</Proof>

<Theorem name="Theorem 5 (the rationals are countable)">

$\Q$ is countable.

</Theorem>

<Proof>

Every rational number can be written $a/b$ with $a \in \Z$ and $b \in \{1, 2, 3, \dots\}$. Define a list of rationals by $q_k = z(m)/(n + 1)$, where $(m, n)$ is the pair with $\pi(m, n) = k$ (Theorem 4) and $z$ is the zigzag of Theorem 3. Given $a/b$, choose $m$ with $z(m) = a$ and let $n = b - 1$; then $a/b = q_{\pi(m, n)}$. So every rational appears in the list (many times, since $1/2 = 2/4 = \cdots$), and $\Q$ is countable by Lemma 1(c).

</Proof>

There is even a list of the positive rationals with **no** repetitions and no cancelling: the *Calkin–Wilf sequence* $1, \tfrac12, 2, \tfrac13, \tfrac32, \tfrac23, 3, \tfrac14, \dots$, in which each term $x$ is followed by $1/(2\lfloor x \rfloor - x + 1)$ (Neil Calkin and Herbert Wilf, 2000; the formula is due to Moshe Newman). The computation section runs it.

<Theorem name="Theorem 6 (countable unions)">

If $A_0, A_1, A_2, \dots$ are countable sets, then their union $\bigcup_i A_i$ is countable.

</Theorem>

<Proof>

We may assume each $A_i$ is non-empty (empty ones contribute nothing; if all are empty the union is empty). For each $i$ choose a list $f_i(0), f_i(1), \dots$ of $A_i$ in which every element appears (Lemma 1, allowing repetitions; a finite set can be listed by repeating its last element). Then $k \mapsto f_m(n)$, where $\pi(m, n) = k$, is a list in which every element of every $A_i$ appears. By Lemma 1(c) the union is countable.

</Proof>

<Note>

The proof *chooses* a list for each of infinitely many sets at once. In axiomatic set theory this needs (a weak form of) the axiom of choice — see <TopicLink id="math.found.axiom-of-choice">the axiom of choice</TopicLink>. When the lists are given explicitly, as in all our examples, no choice is needed.

</Note>

A consequence: the **algebraic numbers** — real numbers that are roots of non-zero polynomials with integer coefficients, such as $\sqrt{2}$, $\sqrt[3]{5}$ and $\tfrac12(1 + \sqrt{5})$ — form a countable set. There are countably many polynomials of each degree (their coefficient lists form a countable set, by Theorem 4 applied repeatedly), each has finitely many roots, and Theorem 6 collects them all.

</Section>

<Section id="uncountable" kind="proof" title="Sets that cannot be listed">

<Theorem name="Theorem 7 (Cantor's theorem)">

For every set $A$, there is no surjection $f : A \to \mathcal{P}(A)$. Consequently $|A| < |\mathcal{P}(A)|$.

</Theorem>

<Proof>

Let $f : A \to \mathcal{P}(A)$ be any function. Consider the **diagonal set**

$$
D = \{a \in A : a \notin f(a)\} \subseteq A .
$$

Suppose $D = f(d)$ for some $d \in A$. If $d \in D$, then by the definition of $D$, $d \notin f(d) = D$. If $d \notin D$, then $d \notin f(d)$, so by the definition of $D$, $d \in D$. Both cases are impossible, so $D$ is not a value of $f$, and $f$ is not surjective. Finally, $a \mapsto \{a\}$ is an injection $A \to \mathcal{P}(A)$, so $|A| \le |\mathcal{P}(A)|$; since there is no bijection, $|A| < |\mathcal{P}(A)|$.

</Proof>

So there is no largest infinity: $|\N| < |\mathcal{P}(\N)| < |\mathcal{P}(\mathcal{P}(\N))| < \cdots$. For a finite set the theorem says $n < 2^n$; for $\N$ it says the subsets of $\N$ cannot be listed.

A subset $S \subseteq \N$ is the same thing as an infinite sequence of 0s and 1s (put $1$ in position $n$ exactly when $n \in S$). In that language Cantor's proof is the famous **diagonal argument**:

<Theorem name="Theorem 8 (0–1 sequences)">

The set of infinite sequences of 0s and 1s is uncountable.

</Theorem>

<Proof>

Given any list $s_0, s_1, s_2, \dots$ of such sequences, define a sequence $d$ by making its $n$-th entry the *opposite* of the $n$-th entry of $s_n$. Then $d$ differs from $s_0$ in entry $0$, from $s_1$ in entry $1$, and in general from $s_n$ in entry $n$. So $d$ is not on the list. Since every list misses a sequence, the set is uncountable.

</Proof>

<Theorem name="Theorem 9 (the real numbers are uncountable)">

The interval $[0, 1)$, and hence $\R$, is uncountable.

</Theorem>

We use two facts about decimals (see <TopicLink id="math.number.real-numbers">real numbers</TopicLink>): every $x \in [0, 1)$ has a decimal expansion $0.d_1 d_2 d_3 \dots$ that does not end in an infinite run of 9s, and two *different* expansions of this kind name *different* numbers. (The only way one number can have two expansions is like $0.5000\dots = 0.4999\dots$)

<Proof>

Suppose $r_1, r_2, r_3, \dots$ were a list of all numbers in $[0, 1)$. Write each in its expansion without a tail of 9s, $r_n = 0.d_{n1} d_{n2} d_{n3} \dots$ Define $x = 0.e_1 e_2 e_3 \dots$ by

$$
e_n = \begin{cases} 4 & \text{if } d_{nn} = 5, \\ 5 & \text{otherwise.} \end{cases}
$$

The digits of $x$ are all 4s and 5s, so this is an expansion without a tail of 9s, and $x \in [0, 1)$. It differs from the expansion of $r_n$ in the $n$-th digit, so by the second fact $x \neq r_n$ — for every $n$. So $x$ is not on the list, a contradiction. Since $[0, 1) \subseteq \R$ and a subset of a countable set is countable (compose the inclusion with an injection into $\N$ and use Lemma 1(b)), $\R$ is uncountable too.

</Proof>

Choosing the digits 4 and 5 is not fussiness: a careless rule could produce $x = 0.4999\dots$, which is the listed number $0.5$ in disguise (the computation section builds exactly this trap).

<Theorem name="Corollary 10 (Cantor, 1874)">

Transcendental numbers exist: some real numbers are not roots of any non-zero polynomial with integer coefficients. Indeed, all but countably many real numbers are transcendental.

</Theorem>

<Proof>

The algebraic numbers form a countable set (end of the previous section), and $\R$ is uncountable. So $\R$ is not equal to the set of algebraic numbers; in fact removing a countable set from $\R$ leaves an uncountable set, since the union of two countable sets is countable.

</Proof>

This proof does not exhibit a single transcendental number! Explicit ones had been found by Joseph Liouville in 1844, such as $\sum_{n \ge 1} 10^{-n!} = 0.110001000\dots$; Charles Hermite proved $e$ transcendental in 1873 and Ferdinand von Lindemann proved the same for $\pi$ in 1882.

**How big is $\R$?** In fact $|\R| = |\mathcal{P}(\N)|$: binary expansions give an injection $[0, 1) \to \mathcal{P}(\N)$, decimal expansions using only the digits 0 and 1 give an injection back, and the Schröder–Bernstein theorem (see <TopicLink id="math.found.cardinals">ordinals and cardinals</TopicLink>) turns two injections into a bijection. Is there a set strictly larger than $\N$ but strictly smaller than $\R$? Cantor conjectured not — the **continuum hypothesis**. Kurt Gödel (1940) and Paul Cohen (1963) showed that, if the standard axioms of set theory (ZFC) are consistent, they can neither prove nor refute it; see <TopicLink id="math.found.forcing">forcing and independence</TopicLink>.

</Section>

<Section id="misconceptions" kind="misconceptions" title="Common misconceptions">

<Misconception>

**"A proper subset of an infinite set must be smaller."** The even numbers are a proper subset of $\N$, yet $n \mapsto 2n$ matches them perfectly with $\N$. For infinite sets "part" does not imply "smaller" — Dedekind even used this property to *define* infinite sets.

</Misconception>

<Misconception>

**"Just add the diagonal number to the list."** You can — but the new list has a new diagonal, which is missing from it. The theorem is not that one particular list is incomplete; it is that **every** list is.

</Misconception>

<Misconception>

**Forgetting that $0.4999\ldots = 0.5$.** A careless diagonal rule might produce $0.4999\ldots$, which equals $0.5$ and may well be on the list. The proof avoids the problem by never using the digits 0 and 9.

</Misconception>

<Misconception>

**"$\Q$ is dense — between any two rationals there is another — so it must be uncountable."** Density is about order, countability about matching. $\Q$ is dense and countable; Theorem 5 lists it.

</Misconception>

<Misconception>

**"Countable means we could finish counting."** A countably infinite set can never be counted to the end. Countable means each element appears at some finite position in one infinite list.

</Misconception>

<Section id="viewpoints" kind="viewpoints" title="Many ways of seeing">

<Viewpoint lens="analysis" title="countable sets have length zero">

Cover the $n$-th point of a countable set $\{q_0, q_1, q_2, \dots\} \subseteq \R$ by an interval of length $\varepsilon / 2^{n+1}$. The intervals have total length at most $\varepsilon/2 + \varepsilon/4 + \dots = \varepsilon$, for any $\varepsilon > 0$ we like. So every countable set — $\Q$ included — has **measure zero**. Since $[0, 1]$ has length $1$ (and one can prove it cannot be covered by countably many intervals of total length less than $1$), this gives a second proof that $[0, 1]$ is uncountable, and says more: the rationals, although dense, are a negligible part of the line.

</Viewpoint>

<Viewpoint lens="topology" title="the Baire category theorem">

A third proof comes from topology. The **Baire category theorem** says that a non-empty complete metric space, such as $\R$, is not a countable union of *nowhere dense* sets (closed sets containing no interval). A single point is nowhere dense, so $\R$ is not a countable union of points: it is uncountable. The same theorem shows that a non-empty complete metric space with no isolated points — the Cantor set, for instance — is uncountable, and it is a workhorse of analysis, for example in showing that "most" continuous functions are nowhere differentiable.

</Viewpoint>

<Viewpoint lens="number-theory" title="algebraic and transcendental">

Counting separates the algebraic numbers (countable) from the transcendental ones (uncountable, so "almost all" real numbers). Yet proving that a *particular* number is transcendental is hard: Liouville (1844), Hermite for $e$ (1873), Lindemann for $\pi$ (1882), and the Gelfond–Schneider theorem (1934) for numbers such as $2^{\sqrt{2}}$. Whether $e + \pi$ is irrational is still unknown. Cantor's argument shows the transcendental numbers are everywhere; number theory is the art of catching one.

</Viewpoint>

<Viewpoint lens="computation" title="most numbers cannot be computed">

A computer program is a finite string of symbols from a finite alphabet, so there are only countably many programs. A real number is *computable* if some program prints its decimal digits one after another for ever. Hence only countably many real numbers are computable, and almost all real numbers can never be computed by any program. Alan Turing (1936) used a diagonal argument in the same spirit to show that no program can decide, for every program, whether it eventually halts; see <TopicLink id="math.comp.computability">computability</TopicLink>.

</Viewpoint>

<Viewpoint lens="logic" title="diagonal arguments elsewhere">

The diagonal pattern reappears across logic: in Russell's paradox (next door, in <TopicLink id="math.found.russell-paradox">Russell's paradox</TopicLink>), in Turing's halting problem, and — in spirit, though the construction is different — in Gödel's incompleteness theorems, whose key step is a sentence that says of itself that it is unprovable; see <TopicLink id="math.found.incompleteness">incompleteness</TopicLink>.

</Viewpoint>

<Section id="history" kind="history" title="History and global context">

- **Ancient and medieval puzzles.** Greek philosophers debated the infinite since Zeno; Aristotle accepted only "potential" infinity. Jaina cosmological texts in India, from roughly the last centuries BCE, classified quantities as enumerable, innumerable and infinite, and distinguished several kinds of infinity — a striking early recognition, in a very different framework from Cantor's, that "infinite" need not be one thing.
- **Galileo** (*Two New Sciences*, 1638) matched the squares with the counting numbers and concluded that infinite quantities cannot be compared. **Bernard Bolzano**'s *Paradoxes of the Infinite* (published 1851) took matchings of infinite sets seriously.
- **Georg Cantor** proved in 1874 that the algebraic numbers are countable and the real numbers are not (his first proof used nested intervals, not diagonals). In 1877 he found a bijection between a line segment and a square and wrote to Richard Dedekind, "Je le vois, mais je ne le crois pas" — "I see it, but I don't believe it". The diagonal argument appeared in 1891. Cantor's ideas met fierce opposition from some contemporaries, but David Hilbert declared in 1925 that "no one shall expel us from the paradise that Cantor has created".
- **Independence.** Kurt Gödel (1940) and Paul Cohen (1963) settled the logical status of Cantor's continuum hypothesis: it is independent of the usual axioms. Cohen received the Fields Medal in 1966 for this work.

</Section>
